风险管理识别、度量并约束不利结果。量化系统里它贯穿组合构建、执行与监控，而不是回测结束后的附加表。

## 风险类型（常用划分）

| 类型 | 例子 |
|------|------|
| 市场风险 | 价格、利率、汇率、波动率变动 |
| 信用风险 | 违约、评级下迁、对手方风险 |
| 流动性风险 | 无法按预期价格变现 |
| 操作与模型风险 | 错误数据、错误代码、错误假设 |
| 合规风险 | 交易限制、信息披露、销售适当性 |

## VaR 与 CVaR

| 指标 | 含义 |
|------|------|
| VaR（Value at Risk） | 在给定置信水平与持有期下，损失「不超过」某阈值的统计度量 |
| CVaR / ES | 超过 VaR 阈值时损失的条件期望，更关注尾部 |

常见估计：历史模拟、参数法（如正态假设）、蒙特卡洛。问答必须说清：持有期、置信水平、损益定义（绝对/相对）、是否含非线性头寸。

VaR **不是**「最大可能损失」，也不能替代压力测试。

## Beta 与敞口

| 概念 | 用途 |
|------|------|
| Beta | 相对基准或因子的敏感度；对冲比率的基础 |
| 名义敞口 | 头寸市值或合约名义本金 |
| 因子敞口 | 风格/行业/国家等风险因子上的暴露 |
| 净敞口 / 总敞口 | 多空组合的方向性与杠杆画像 |

敞口限额常按单票、行业、风格、总杠杆设置，并与 [组合优化](/knowledge/portfolio) 约束一致。

## 止损与限额

| 机制 | 注意 |
|------|------|
| 价格止损 | 跌停或跳空时可能无法按止损价成交 |
| 波动止损 / ATR 止损 | 随波动调整，需定义计算窗口 |
| 组合回撤熔断 | 达到阈值降仓或停策略 |
| 希腊字母 / 久期限额 | 衍生品与债券组合 |

止损是风险控制工具，不是提高期望收益的保证。

## 压力测试与情景

- **历史情景**：重放危机区间的收益与相关性。
- **假设情景**：利率急升、流动性枯竭、单名暴雷等。
- **反向压力**：先定致命损失，反推需要何种冲击。

A 股还需测试涨跌停、停牌与流动性骤降，见 [A股回测陷阱](/knowledge/evaluation/ashare-pitfalls)。

## 与绩效指标的关系

夏普、最大回撤等既是绩效也是风险结果展示，见 [评价指标](/knowledge/evaluation/metrics)。风险管理更强调事前限额与事后归因，而不仅是样本内曲线好看。

## 常见误用

- 用短期平静期估计 VaR，低估尾部。
- 假设正态且资产可连续交易，忽略涨跌停。
- 多层止损叠加却无总体风险预算。
