知识库条目尽量可追溯到公开权威资料。本页给出来源分级、主题对照和使用约定，方便检索切片与回答时标注出处。

## 使用约定

1. **优先官方原文**：交易规则、信披、指数编制以证监会、交易所、指数公司公告为准。
2. **库与文档对齐口径**：技术指标命名与分组参考 TA-Lib；因子与研究流程参考 Qlib / 主流多因子框架；策略与回测范式参考 RiceQuant、QuantConnect 等公开文档。
3. **标明适用范围**：全球通用概念与 A 股特有规则分开写；参数默认值只作常见习惯，不是法规。
4. **禁止臆造**：费率、阈值、精确条文编号、实时数据不以知识库摘要代替原文或接口。
5. **版本敏感**：规则与接口会变；回答时应提示核对官网或数据服务时间戳。

## 优先级与主题对照

| 优先级 | 先覆盖什么 | 主要来源 |
|--------|------------|----------|

## 来源类型说明

| 类型 | 适合引用什么 | 注意 |
|------|--------------|------|
| 交易所/监管官网 | 交易时段、涨跌幅、ST、停牌、信披义务 | 以最新规则与通知为准 |
| 指标库文档（TA-Lib） | 函数名、输入输出、功能族分类 | 实现细节因语言绑定而异 |
| 研究框架（Qlib） | 因子研究流水线、数据集约定、模型实验组织 | 因子定义需与本地指标字典对齐 |
| 量化平台文档 | 回测假设、订单类型、绩效指标含义 | 平台默认假设可能与 A 股撮合不同 |
| 教材与公开课 | 概率统计、组合优化、随机过程基础 | 符号体系可能与业务口径不一致 |
| 预印本/论文（arXiv） | 方法思路、评估设定 | 未经同行评审时标注为研究材料 |

## 页内「来源」小节怎么写

知识库各页文末「来源」一般包含：

- 本页主要依据的网站或文档名称与链接
- 若规则可能变更，一句提醒核对官网
- 不把未核对的二手博客当作唯一依据

## 与产品文档的边界

| 内容 | 放哪里 |
|------|--------|
| 领域定义、分类、通用公式、A 股规则要点 | 知识库 |
| 本系统表结构、API、回测引擎行为 | 指南 / 数据 / API / 回测 |
| 方案选型、Agent 架构、评测方法 | 调研 |
