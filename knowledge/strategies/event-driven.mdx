事件驱动策略在可知的公司或宏观事件附近交易，赚取事件引起的价格调整或风险溢价。关键是事件时间戳与可交易性，而不是事后叙事。

## 常见事件类型

| 类型 | 例子 |
|------|------|
| 盈余 | 业绩预告、快报、正式报告、电话会 |
| 资本运作 | 回购、增发、减持、股权激励 |
| 并购重组 | 停牌、方案进展、失败重启 |
| 指数事件 | 纳入/剔除重要指数 |
| 宏观与政策 | 利率决议、监管新政、假期效应 |

## 研究设计

1. **事件定义**：纳入标准、清洗重复公告。
2. **时间轴**：公告时点、盘前盘后、下一可交易时刻。
3. **窗口收益**：事件前漂移、公告反应、事后漂移分开统计。
4. **对照**：行业/市值匹配或市场模型异常收益。
5. **可交易规则**：能否在信号价成交，是否撞涨跌停。

## 风险

- 停牌使事件期无法交易或复牌一字板。
- 信息提前泄露与「传闻」噪声。
- 样本外事件类型分布变化（监管环境变）。
- 多重检验：翻很多事件类型后的幸运结果。

## A 股注意点

- 信披规则与停牌制度见 [信息披露](/knowledge/cn-market/disclosure)、[涨跌停与停牌](/knowledge/cn-market/limit-st-suspend)。
- 并购重组类策略高度依赖停复牌与审核进度。
- 业绩披露扎堆期，拥挤与冲击上升。

## 常见误用

- 用最终成功的并购样本回测，忽略失败与终止案（幸存者偏差）。
- 以公告当日收盘才知道的信息按开盘价成交。
- 把新闻标题情绪直接当仓位，无事件类型过滤。
