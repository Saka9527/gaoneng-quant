量化研究依赖概率、统计与线性代数描述收益与风险。本页给出问答常用符号与直觉，不展开完整证明；组合优化见 [组合优化](/knowledge/portfolio)，评估指标见 [评价指标](/knowledge/evaluation/metrics)。

## 概率统计

| 概念 | 量化里怎么用 |
|------|----------------|
| 随机变量与分布 | 收益、残差、因子暴露的建模假设 |
| 期望、方差、标准差 | 平均收益与波动；标准差常作波动率代理 |
| 协方差与相关 | 资产联动、分散化、因子共线性 |
| 分位数 | VaR、收益分布尾部 |
| 假设检验 | t 检验、IC 显著性；注意多重检验 |

收益常用简单收益 \(R_t = P_t/P_{t-1}-1\) 或对数收益 \(r_t=\ln(P_t/P_{t-1})\)。回测与统计要事先约定用哪一种。

## 线性代数

| 概念 | 用途 |
|------|------|
| 向量 / 矩阵 | 组合权重、因子载荷、收益协方差矩阵 |
| 特征值分解 | 风险模型、主成分（PCA）降维 |
| 最小二乘 | 截面/时序回归估计因子收益或对冲系数 |

权重向量 \(w\)、协方差 \(\Sigma\) 时，组合方差为 \(w^\top \Sigma w\)。

## 时间序列

| 概念 | 要点 |
|------|------|
| 平稳性 | 许多统计方法假设均值/方差稳定；价格常非平稳，收益更接近平稳 |
| 自相关 | 检验收益或残差是否还有可预测结构 |
| 滞后与滚动窗口 | 动量、波动率、均线都依赖窗口定义 |
| 结构突变 | 制度变更、成分调整会使历史参数失效 |

## 回归分析

常用形式：

- **时序回归**：资产收益对市场或因子序列回归，得到 beta 与残差。
- **截面回归**：同一交易日多资产收益对因子暴露回归，得到因子收益。
- **面板**：兼顾截面与时间，需处理固定效应与误差结构。

注意：样本内拟合好不等于样本外有效；多重共线会使系数不稳定。

## 随机过程（概念级）

| 模型直觉 | 用途 |
|----------|------|
| 随机游走 / 鞅 | 价格难预测的基线假设 |
| 布朗运动与几何布朗运动 | 连续时间定价与模拟的入门模型 |
| 均值回复过程 | 利率、价差、某些相对价值策略 |
| 波动率聚集 | GARCH 类：波动随时间变化 |

衍生品定价与随机微积分细节超出本页；需要时查公开金融工程课程（Open-MFE、QuantEcon 等）。

## A 股注意点

- 涨跌停与停牌造成收益截断与缺失，统计分布与连续交易市场不同。
- 日历用交易日而非自然日；年化时常按约 242/252 个交易日约定，需写明。
- 复权与公司行为会改变价格序列，指标与回归输入要统一复权口径。

## 常见误用

- 把高 \(R^2\) 当成可交易 alpha。
- 对重叠窗口滚动收益做检验却忽略序列相关。
- 混用简单收益与对数收益却直接相加或年化。
