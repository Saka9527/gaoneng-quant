波动与流动性因子刻画交易风险与变现成本相关的特征。低波动异象、流动性溢价等结论依赖市场与样本，使用前需本地验证。

## 波动类

| 因子 | 要点 |
|------|------|
| 历史波动 | 收益标准差；窗口与年化约定 |
| 特异质波动 | 对市场/因子回归后的残差波动 |
| ATR / NATR | 见 [波动率指标](/knowledge/indicators/volatility) |
| 上下行波动 | 涨跌日波动不对称 |

## 流动性类

| 因子 | 要点 |
|------|------|
| 换手率 | 成交量/流通股本；极端换手可能是事件 |
| 成交额 | 绝对流动性；需市值或分位标准化 |
| Amihud 非流动性 | 单位成交额引起的价格冲击代理 |
| 买卖价差代理 | 高频或日频高低价差类指标 |

## 处理要点

1. **截面比较**：用分位数或行业内排序，避免大票小票绝对波动直接比。
2. **公司行为日**：除权日、异常放量日可临时扭曲指标。
3. **与组合约束**：流动性因子常用于剔除或降权，而不是唯一 alpha。
4. **成本联动**：回测成本模型应与流动性假设一致，见 [交易执行](/knowledge/execution)。

## A 股注意点

- 涨跌停日收益与波动被截断，流动性表象（封单）与真实可买可卖不同。
- 自由流通换手与总股本换手口径不同。
- 停牌复牌后的换手与波动跳变。

## 常见误用

- 把「低波动」无条件当成「低风险可加杠杆」。
- 用未来一段时间的平均成交额做当日权重（前视）。
- 在流动性差的股票上假设零冲击成交。
