价值因子衡量价格相对基本面的便宜程度。逻辑是：相对资产盈利、净资产或分红，市场价格偏低的股票长期可能获得补偿（是否成立需样本外验证）。

## 常用因子

| 因子 | 常见口径 | 注意 |
|------|----------|------|
| PE（市盈率） | 价格 / 盈利；TTM 或预测盈利 | 亏损股 PE 无意义，常用掩码或单独处理 |
| PB（市净率） | 市值 / 净资产 | 会计净资产口径、商誉与减值 |
| PS（市销率） | 市值 / 营收 | 收入含金量因行业而异 |
| 股息率 | 分红 / 市值或股价 | 分红政策与一次性分红 |
| EV/EBITDA 等 | 企业价值相对经营利润 | 需净现金、少数股东等调整 |

## 处理要点

1. **去极值与标准化**：截面 MAD/分位数截断，再 Z-Score 或排序分位。
2. **行业中性**：价值在行业间天然差异大，常先做行业内排序。
3. **财务时点**：用公告可得数据，避免未来财报泄漏。
4. **负盈利 / 负账面**：规则要事先写清（剔除、单独分组或用分位数秩）。

## 与策略

价值常与质量、动量组合，缓解「便宜但基本面恶化」的价值陷阱，见 [多因子策略](/knowledge/strategies/multi-factor)、[质量因子](/knowledge/factors/quality)。

## A 股注意点

- 结构市值、自由流通市值口径影响分母。
- ST、风险警示股可能「看起来很便宜」。
- 会计政策与非经常性损益影响盈利质量。

## 常见误用

- 混用 TTM、LYR、预测一致预期却不声明。
- 用当日收盘价与尚未公告的年报盈利配对。
- 忽略金融股与一般企业会计科目差异。
