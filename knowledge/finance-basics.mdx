金融基础覆盖常见资产与市场机制的定义，方便问答先对齐「在说哪一类工具」。本页偏概念框架；A 股细则见 [A股规则](/knowledge/cn-market/overview)，量化计算见后续指标与因子页。

## 股票

股票代表对公司剩余权益的份额。常见维度：

| 概念 | 含义 |
|------|------|
| 发行与流通 | 总股本、流通股本；限售与解禁影响可交易供给 |
| 价格与复权 | 除权除息后需复权才能比较历史收益 |
| 收益来源 | 价差、分红；总回报需含再投资假设 |
| 风险特征 | 波动、流动性、个股事件、市场系统性风险 |

A 股还需关注涨跌停、ST、停牌与交易时段，见 [涨跌停与停牌](/knowledge/cn-market/limit-st-suspend)。

## 基金

基金是集合投资工具，按投资范围与结构分类：

| 类型 | 要点 |
|------|------|
| 开放式 / 封闭式 | 申赎机制与流动性不同 |
| 股票型 / 债券型 / 混合型 / 货币型 | 风险收益特征不同 |
| ETF / LOF | 可在交易所交易；ETF 常有一二级套利机制 |
| 指数型 / 主动型 | 跟踪误差 vs 主动超额 |

问答时先确认：净值日、费用是否计入、比较基准是什么。

## 债券

债券是约定还本付息的债权凭证。核心概念：面值、票息、到期收益率（YTM）、久期、凸性、信用利差。利率上升通常压低既有固息债价格。信用债需区分利率风险与违约/评级风险。

## 期货与期权

| 工具 | 要点 |
|------|------|
| 期货 | 标准化远期合约；保证金、盯市、到期交割或平仓 |
| 期权 | 权利而非义务；看涨/看跌、行权价、到期日；权利金与希腊字母用于风险管理 |

衍生品用于套期保值、投机与套利；问答需分清标的、乘数、到期与保证金规则（以交易所规则为准）。

## 市场机制

| 机制 | 说明 |
|------|------|
| 订单簿 / 竞价 | 买卖申报撮合；集合竞价与连续竞价规则因市场而异 |
| 做市 | 做市商提供双边报价，改善流动性 |
| 清算交收 | 成交后资金与证券结算；T+N 因市场而异 |
| 指数 | 加权方式、样本调整、可投资性影响产品与策略 |

A 股交易时段与竞价见 [交易时段](/knowledge/cn-market/trading-session)。

## 财务知识（读报表）

三张表：

| 报表 | 关注什么 |
|------|----------|
| 利润表 | 收入、成本、毛利、营业利润、净利润 |
| 资产负债表 | 资产、负债、所有者权益；杠杆与偿债 |
| 现金流量表 | 经营、投资、筹资现金流；利润与现金是否匹配 |

常用财务比率：ROE、ROA、毛利率、资产负债率、流动比率、经营现金流/净利润。因子化用法见 [价值因子](/knowledge/factors/value)、[质量因子](/knowledge/factors/quality)。

## 常见误用

- 把「价格涨跌」直接当成「投资回报」而忽略分红与复权。
- 跨市场比较时忽略交易制度、税费与交收差异。
- 用单一财务指标下投资结论，不看口径、一次性损益与可比公司。
