A 股制度与微观结构使「按收盘价随意成交」的回测容易高估。本页列出问答与研究中应主动检查的陷阱；规则要点见 [A股规则](/knowledge/cn-market/overview)。

## 成交与制度

| 陷阱 | 后果 | 缓解 |
|------|------|------|
| 忽略涨跌停 | 假想买到封死的涨停股 | 标记不可买/不可卖，延迟或撤单 |
| 忽略停牌 | 无量日仍调仓 | 停牌期冻结，复牌再处理 |
| 信号日收盘成交 | 用收盘信息以收盘价成交 | 下一可交易开盘或显式延迟 |
| 忽略 T+1 | 当日回转卖出 | 持仓最短持有约束 |
| 忽略整手/价位 | 权重无法精确实现 | 数量取整与剩余现金处理 |

## 数据与口径

| 陷阱 | 说明 |
|------|------|
| 复权混乱 | 前复权做信号、不复权算收益却未对齐 |
| 财务未来函数 | 用报告期归属日而非公告日 |
| 幸存者偏差 | 剔除已退市股票 |
| 指数失真 | 用价格点位当可投资收益，忽略分红与成分调整 |
| 分钟数据对齐 | 时间戳时区与集合竞价时段处理错误 |

## 成本与容量

- 小票策略在历史均价成交假设下容量虚高。
- 印花税、佣金、过户费等应分买卖方向建模（具体费率以当时规则与券商约定为准，不在此写死数字）。
- 冲击成本随参与率上升，见 [交易执行](/knowledge/execution)。

## 评估解读

- 报告涨跌停阻断次数、未成交比例。
- 分市值分层看收益是否只来自小票。
- 对主题抱团期单独做稳健性检查。

## 常见误用

- 「全市场任意股票、任意仓位、零成本」回测当出品标准。
- 用未复权价格算长期动量。
- 把不可融券的空头收益算进多空净值。
