回测用历史数据模拟策略规则，评估其收益与风险特征。它回答「在既定假设下过去会怎样」，不保证未来。本栏目覆盖指标、过拟合与 A 股陷阱。

## 回测要写清的假设

| 假设 | 为什么重要 |
|------|------------|
| 成交价 | 开盘/收盘/VWAP/下一根 K 线，决定是否前视 |
| 成交量与冲击 | 大单是否按理想价全部成交 |
| 费用与税 | 佣金、印花税、滑点模型 |
| 复权与公司行为 | 收益是否可比 |
| 停牌与涨跌停 | 订单是否失败或延迟 |
| 融资融券 | 空头是否可实现 |

产品侧回测流程见 [回测流程](/backtest/flow)；知识层陷阱见 [A股回测陷阱](/knowledge/evaluation/ashare-pitfalls)。

## 评估分层

1. **信号层**：IC、IR、胜率、分层收益，见 [评价指标](/knowledge/evaluation/metrics)。
2. **组合层**：净值、回撤、换手、敞口、成本后收益。
3. **稳健性**：子区间、参数扰动、成本上调、见 [过拟合](/knowledge/evaluation/overfitting)。
4. **可交易性**：涨跌停触及率、未成交率、流动性约束。

## 解读原则

- 先看假设是否可复现，再看曲线是否好看。
- 样本内与样本外分开报告。
- 高换手策略必须报告成本后结果。
- 问答应区分回测结果与实盘期望。
