评价指标把回测或因子研究结果压缩成可比较的数字。同一名称在不同平台可能有细微差别，问答应声明计算窗口与无风险利率等约定。

## 因子预测力

| 指标 | 含义 |
|------|------|
| IC | 因子值与前瞻收益的截面相关（Pearson 或 Spearman/Rank IC） |
| IC 均值 / 标准差 | 预测力水平与稳定性 |
| IR（信息比率，因子语境） | 常指 IC 均值 / IC 标准差（注意与组合 IR 不同口径） |
| 分层收益 | 按因子分位数分组的收益单调性 |

## 组合绩效

| 指标 | 含义 |
|------|------|
| 累计收益 / 年化收益 | 依赖复利与年化交易日约定 |
| 波动率 | 收益标准差，常年化 |
| 夏普比率 | 超额收益 / 波动；无风险利率与年化方式需声明 |
| 最大回撤 | 净值高峰到低谷的最大跌幅 |
| Calmar 等 | 收益相对回撤的比率类指标 |
| 胜率 / 盈亏比 | 依赖「一笔交易」的定义 |
| 换手率 | 双边或单边，影响成本敏感性 |
| 跟踪误差 / 信息比率（组合） | 相对基准主动收益 / 跟踪误差 |

## empyrical 等库

Python 生态常用 `empyrical` 等库计算夏普、回撤等。使用时锁定版本，并核对其年化因子与收益输入是简单收益还是对数收益。

## 使用建议

1. 不要只看夏普；同时看回撤、换手、集中度。
2. 因子 IC 好不等于加入成本后组合能赚钱。
3. 分市场状态报告（牛/熊/震荡）比单一全样本数字更有信息。

## 常见误用

- 把因子 IR 与组合信息比率混为一谈。
- 用未扣成本的夏普做上线决策。
- 在重叠收益率上算夏普却不调整自由度。
