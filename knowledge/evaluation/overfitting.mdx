过拟合指策略或模型过度贴合历史样本的噪声，导致样本外失效。量化研究自由度很高（参数、因子、区间、过滤规则），过拟合是默认风险而非例外。

## 常见来源

| 来源 | 例子 |
|------|------|
| 参数搜索 | 对均线长度网格搜索后只保留最佳 |
| 因子堆积 | 不断加入「这次有效」的因子 |
| 区间挑选 | 只展示策略好看的年份 |
| 多重检验 | 试了 100 个想法只报成功的 1 个 |
| 前视偏差 | 使用当时不可得的信息 |
| 幸存者偏差 | 只用目前仍上市的股票 |

## 缓解方法

1. **事前写明假设**，冻结后再回测。
2. **样本切割**：训练 / 验证 / 测试，测试集少动。
3. **走步前进（walk-forward）** 或滚动训练。
4. **成本压力测试**：提高滑点与佣金后是否仍成立。
5. **参数平坦性**：最优附近是否陡峭（陡峭通常不稳健）。
6. **记录研究次数**：对显著性和期望做折扣。
7. **经济逻辑**：说得出为何应有收益，而不只是曲线拟合。

## 与机器学习

特征选择、早停、正则、交叉验证都必须遵守时间顺序，见 [机器学习与AI](/knowledge/ml-ai)。随机打乱时序验证会系统性乐观。

## 问答系统中的表述

当用户问「这个回测夏普 3 能不能信」时，应检查：成本、成交假设、样本外、参数搜索范围与是否 A 股可交易约束，而不是只复述数字。

## 常见误用

- 把验证集当测试集反复使用。
- 用全样本最优参数直接「样本外」却其实已泄漏。
- 忽略交易成本与容量，宣称策略可无限放大。
