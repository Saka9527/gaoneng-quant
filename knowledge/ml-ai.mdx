机器学习与 AI 用于从数据中学习预测或决策规则。量化场景里，模型必须服从金融数据的时序结构、交易成本与合规约束。系统落地架构见 [AI问答与优化](/research/ai-qa)、[AI量化交易](/research/ai-quant)。

## 监督学习

| 任务 | 例子 |
|------|------|
| 回归 | 预测未来收益、波动、因子值 |
| 分类 | 涨跌方向、事件是否发生、股票池入选 |
| 排序 / 学习排序 | 截面排序与多因子合成 |

要点：严格时间切分（训练/验证/测试），避免未来函数；标签定义（前瞻收益窗口、复权）必须固定。特征可来自价量、财务与另类数据，见 [量化因子](/knowledge/factors/overview)。

## 深度学习

深度模型（MLP、时序网络、Transformer 等）适合高维非线性，但也更容易过拟合与难解释。

- 需要更多数据与正则、早停、结构约束。
- 输出若是交易信号，仍要过组合、执行与风控层。
- 可解释性与归因在投研与合规场景往往必要。

## 强化学习（RL）

RL 把交易或调仓看成序贯决策，优化长期奖励（如收益减成本减回撤惩罚）。

| 难点 | 说明 |
|------|------|
| 非平稳 | 市场分布漂移 |
| 低信噪比 | 奖励稀疏、方差大 |
| 仿真偏差 | 训练环境与真实撮合不一致 |
| 评估 | 不能只看训练曲线，需样本外与成本敏感回测 |

## LLM 与 Agent

| 角色 | 适合 | 不适合 |
|------|------|--------|
| LLM | 理解问题、检索知识、解释结果、生成研究草稿 | 充当行情计算器或私下编造回测数字 |
| Agent | 多步调用工具、编排检索与分析 | 无权限校验地自动下单 |

推荐链路：意图解析 → 知识库/工具 → 确定性计算 → 带出处的解释。知识检索约定见 [总览](/knowledge/overview)。

## 与 Qlib 等研究框架

[Qlib](https://github.com/microsoft/qlib) 等框架提供数据、因子、模型与回测实验组织方式，便于复现。接入时仍需对齐：本地数据口径、A 股交易规则、以及本机构的指标字典。

## 过拟合与研究纪律

- 一次只改一个环节，用固定题集或固定测试区间对比，见 [过拟合](/knowledge/evaluation/overfitting)。
- 特征工程、标签与模型选择都算「研究自由度」，需记录版本。
- 金融机器学习文献（含 arXiv 预印本）应用时标注方法来源与假设。

## 常见误用

- 随机打乱时序做交叉验证造成泄漏。
- 用 LLM 直接输出「明日涨跌」当交易指令。
- 把回测夏普优化目标直接当作在线奖励且忽略成本。
