交易执行研究如何把目标仓位变成实际成交，并控制滑点与冲击成本。策略回测若假设「收盘价无摩擦成交」，执行层往往是样本外衰减的主要来源之一。

## 算法订单常用目标

| 算法 | 含义 |
|------|------|
| TWAP | 时间加权：在时段内近似均匀完成数量 |
| VWAP | 成交量加权：跟踪市场成交量分布，使均价接近市场 VWAP |
| POV / Participation | 按市场成交量的一定参与率成交 |

选择取决于紧急程度、流动性与是否要对齐基准成交价。实现细节（切片、限价偏离、暂停条件）因系统而异。

## 订单类型（概念）

| 类型 | 要点 |
|------|------|
| 市价 | 尽快成交，价格不确定 |
| 限价 | 限定最差价格，可能不成交 |
| 止损 / 止损限价 | 触发后转为市价或限价（具体规则看市场） |
| 冰山 / 隐藏 | 减少显示数量，降低信息泄露（若市场支持） |

A 股订单类型与申报规则以交易所业务规则为准，见 [交易时段](/knowledge/cn-market/trading-session)。

## 滑点与冲击成本

| 概念 | 说明 |
|------|------|
| 滑点 | 决策价/基准价与成交均价之差 |
| 买卖价差 | 即时成交的显性成本 |
| 市场冲击 | 自身交易推动价格不利移动 |
| 时机风险 | 分拆执行期间价格朝不利方向漂移 |

成本模型常见做法：把成本写成价差项 + 与成交量/波动相关的冲击项。回测要声明用的是哪套假设。

## 市场微观结构（入门）

- **订单簿**：买卖档位与深度决定大单如何吃价。
- **信息与毒性**：知情交易会让做市或被动单更易亏损。
- **开收盘**：集合竞价与连续竞价的流动性、波动特征不同。
- **成交量分布**：VWAP 类算法依赖历史或实时量能曲线。

## 与回测、风控的衔接

- 回测引擎的成交价假设（开盘/收盘/VWAP 近似）决定绩效可信度，见 [回测评估](/knowledge/evaluation/overview)。
- 涨跌停与停牌使订单无法按计划完成，见 [涨跌停与停牌](/knowledge/cn-market/limit-st-suspend)。
- 执行风险属于操作与市场风险的交叉地带，见 [风险管理](/knowledge/risk)。

## 常见误用

- 用未来成交量曲线做完美 VWAP（前视偏差）。
- 大单回测按收盘价 100% 成交且零冲击。
- 忽略最小价位、整手与申报限制。
