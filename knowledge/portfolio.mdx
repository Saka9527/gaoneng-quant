资产配置决定风险预算如何在资产或因子间分配；组合优化在约束下求权重。本页讲主流框架的定义与适用边界，不给出具体推荐配置。

## 均值方差（Markowitz）

思路：在预期收益与协方差已知时，求给定风险下收益最大（或给定收益下风险最小）的权重。

| 输入 | 含义 |
|------|------|
| 预期收益向量 \(\mu\) | 最难估计，误差对结果很敏感 |
| 协方差矩阵 \(\Sigma\) | 样本协方差需足够历史；高维时需收缩或因子风险模型 |
| 约束 | 权重上下限、行业/风格中性、换手、禁止做空等 |

有效前沿是风险-收益平面上的最优集合。实务中常因 \(\mu\) 不稳而改用最小方差、风险预算或加入观点收缩。

## 风险平价（Risk Parity）

目标：让各资产（或各风险因子）对组合总风险的贡献更均衡，而不是等权重或等名义金额。

- 依赖协方差估计，对收益预测依赖较弱。
- 波动低的资产往往获得更高权重，杠杆与融资约束需单独处理。
- 「风险贡献」定义（边际风险贡献等）要在实现里写死。

## Black-Litterman

在市场均衡权重隐含收益的基础上，融入投资者观点，得到后验预期收益，再做优化。适合「有观点、但不敢完全信任历史均值」的场景。观点权重（信心）与观点矩阵的设定会显著影响结果。

## 常见约束

| 约束 | 为什么需要 |
|------|------------|
| 权重上下限 | 流动性、合规、单票集中度 |
| 行业 / 风格暴露 | 控制非目标风险 |
| 换手与交易成本 | 降低不可实现的高频调仓 |
| 多空与杠杆 | 融资融券、对冲账户规则 |
| 跟踪误差 | 相对基准的主动组合 |

## 与因子、回测的关系

- 多因子选股得到的是得分或股票池；组合层决定持仓权重与再平衡，见 [多因子策略](/knowledge/strategies/multi-factor)。
- 优化结果必须用可交易假设回测：涨跌停、停牌、冲击成本，见 [A股回测陷阱](/knowledge/evaluation/ashare-pitfalls)。
- 风险度量与限额见 [风险管理](/knowledge/risk)。

## 常见误用

- 用很短样本估计高维协方差并直接求逆。
- 优化时忽略成本与约束，样本内夏普虚高。
- 把风险平价当成「无需任何假设」的免费午餐。
