## 1. 信号日和成交日

| 项 | 规则 |
|----|------|
| 指标 | 全部在收盘价上算；标记写在**确认日** K 线下标 |
| 成交 | 下一交易日 `T` 开盘读上一交易日标记，按 `T` 开盘价成交 |
| 当日顺序 | 先卖后买；当天买入 `holdDays = 0`，当天不卖 |
| 不成交 | 停牌、缺 K 线、开盘 ≤ 0；`limitRules` 默认开 |
| T+1 | 默认开：买入日当天不能卖 |

```text
买入成交价 = 开盘 × (1 + 佣金 + 滑点)
卖出成交价 = 开盘 × (1 − 佣金 − 滑点 − 印花税)
默认：佣金 0.0003，滑点 0.0005，印花税 0.0005
```

`sellOnIndicator = false` 时卖出标记整段为 false，只按持股天数平仓。

## 2. 价格口径

默认 `forwardAdjust = true`。

| 用途 | 价格 |
|------|------|
| 均线 / 指标 / 交叉 | 前复权开收盘 |
| 涨跌停公布价比较 | 未复权开盘 vs 公布价 |
| 无公布价时的板幅 | 前复权昨收 × 板幅 |
| 成交额 / 换手 | 同花顺原值 |
| 流通 / 总市值 | 股本 × 未复权收盘 |

面板按库内最新 `cum_back` 前复权；回测再按结束日做点时前复权。结束日不早于该股最新除权时系数为 1。

```text
点时前复权价 = 未复权价 × (不晚于结束日的 cum_back ÷ 不晚于当日的 cum_back)
无因子时乘数 = 1
```

## 3. 共用判定

「上一根」指该股 K 线序列前一根。`NaN` 不参与比较。

| 名称 | 成立条件 |
|------|----------|
| 下穿 | 上一根 `A ≥ B`，这一根 `A < B` |
| 上穿 | 上一根 `A ≤ B`，这一根 `A > B` |
| 下穿水平 `L` | 上一根 `A ≥ L`，这一根 `A < L` |
| 高于 / 低于水平 | 这一根 `A > L` / `A < L` |
| 拐头向下 | 这一根 `<` 上一根，且上一根 `≥` 再上一根 |
| 下移 | 这一根 `<` 上一根 |
| 顶背离 | 回看 20 根（不含今天）：收盘 ≥ 窗口收盘最大，且指标 `<` 窗口指标最大 |

```text
顶背离窗口 = [i−20, i)，不含当天
窗口内 NaN 不进指标最大值；20 根全 NaN 不触发
```

## 4. 指标公式

### 4.1 SMA(N)

`C` 为前复权收盘。`i ≥ N−1` 起有效。

```text
SMA(N)_i = (C_i + C_{i-1} + … + C_{i-N+1}) / N
```

### 4.2 EMA(N)

前 `N` 根收盘 SMA 作种子（下标 `N−1`），之后：

```text
k = 2 / (N + 1)
EMA_i = C_i × k + EMA_{i-1} × (1 − k)
```

对含前导 `NaN` 的序列（如 MACD 的 DEA）：跳过开头 `NaN`，再对有限值做同样种子与 EMA。

### 4.3 RSI

Wilder 平滑。`RSI_SHORT = 6`，`RSI_LONG = 12`。`d_i = C_i − C_{i−1}`，`g_i = max(d_i,0)`，`l_i = max(−d_i,0)`。

首值在下标 `N`：用 `d_1…d_N` 算术平均得 `gain`、`loss`。之后：

```text
gain_i = (gain_{i-1} × (N − 1) + g_i) / N
loss_i = (loss_{i-1} × (N − 1) + l_i) / N

gain = loss = 0  →  50
loss = 0         →  100
否则             →  100 − 100 / (1 + gain / loss)
```

RSI6 从下标 6、RSI12 从下标 12 起有效。

### 4.4 布林带

`N = 20`，`k = 2`。中轨 = SMA(20)。总体标准差（除以 `N`）。下标 19 起有效；负方差按 0。

```text
方差 = Σ(C²) / N − 中轨²
上轨 = 中轨 + 2 × √方差
下轨 = 中轨 − 2 × √方差
```

### 4.5 KDJ

`N = 9`。高低用**收盘**窗口，不用 K 线最高/最低。下标 8：`K = D = RSV`。

```text
HH = max(C_{i-8} … C_i)
LL = min(C_{i-8} … C_i)
HH = LL → RSV = 50
否则    → RSV = (C_i − LL) / (HH − LL) × 100

K_i = (RSV_i + 2 × K_{i-1}) / 3
D_i = (K_i + 2 × D_{i-1}) / 3
J_i = 3 × K_i − 2 × D_i
```

### 4.6 MACD

参数 12、26、9。柱状值不做 `2×`。文案「MACD」在死叉/拐头/下移/穿零/小于 0 中指 **DIF**；「拐头离开」用 HIST。

```text
DIF = EMA(12) − EMA(26)
DEA = 对 DIF 做 EMA(9)（跳过 DIF 前导 NaN）
HIST = DIF − DEA
```

DIF 从下标 25 起有效；DEA 再等 9 根有限 DIF。

### 4.7 金叉强度

仅金叉当天有值，其余预计算为 `1e-6`。`positionMode = INDICATOR` 时按强度占比分预算。

```text
强度 = |SMA短 − SMA长| / SMA长
SMA长 ≤ 0 → 1e-6
```

## 5. 买入规则

共 2 条。标记写在确认日；下一交易日开盘买。默认还需确认日下标 `≥ longMa`（60）。

| `rebalance` | 可买日 |
|-------------|--------|
| `DAILY` | 每个交易日 |
| `WEEKLY` | 周一；跨周首个交易日也可 |
| `MONTHLY` | 与上一交易日不在同月 |

买入还需：未持有、成分包含（配因子时看上一交易日）、未因排除 ST 去掉、流通市值达标、开盘可买、排序后仍有名额、同行业未超限、预算 ≥ 1 股。默认最多持有 10、每日新买 ≤ 2、单票权重 ≤ 10%、总仓位 ≤ 100%。

### 5.1 `SMA_GOLDEN` 双均线金叉（默认）

`i ≥ longMa`。默认 SMA20 上穿 SMA60；相等后再严格上穿才算。

```text
SMA(short)_{i-1} ≤ SMA(long)_{i-1}
且 SMA(short)_i > SMA(long)_i
```

### 5.2 `UNIVERSE_RANK` 成分按排序买入

确认日下标 `≥ 1` 即可买，不看均线。动量回看 = `shortMa` 夹到 5～20（默认 20）。

```text
动量_i = C_i / C_{i−lookback} − 1
昨收或回看收盘 ≤ 0 → 动量 = 0
强度 = max(|动量|, 1e-6)
```

几乎每天全池可买，引擎扫描整个股票池（不建当日买点索引）。

## 6. 卖出规则

共 38 条，只算请求选中的一条。确认日收盘成立 → 下一交易日开盘卖。与持股周期为**或**。停牌 / 跌停 / T+1 拒卖后仓位留到之后再试（`holdDays` 已加）。

```text
买入当天 holdDays = 0
之后每个交易日循环开始 holdDays += 1
holdDays ≥ holdingPeriodDays → 当天开盘卖
默认 holdingPeriodDays = 2
```

| 买入日 | 下一交易日 | 再下一交易日 |
|--------|------------|--------------|
| 买入，`holdDays = 0` | `holdDays = 1` | `holdDays = 2`，周期到达开盘卖 |

### 6.1 短长均线相关

| id | 名称 | 成立 |
|----|------|------|
| `MA_DEATH` | MA死叉（默认） | `i ≥ longMa`：上一根短 ≥ 长，这一根短 &lt; 长 |
| `MA_TOP_DIV` | MA顶背离 | ta4j：`i ≥ shortMa+1`，收盘 = 最近 `shortMa+1` 根收盘最高（含当天），且 SMA 今天 &lt; 昨天 |
| `HOLD_PERIOD` | 仅持股周期 | 标记恒 false，只等持股天数 |

`MA_TOP_DIV` 建 K 线时最高 = max(开,收)，最低 = min(开,收)，成交量 0；比较读收盘。

### 6.2 RSI（6 / 12）

| id | 成立 |
|----|------|
| `RSI_TURN_DOWN` | RSI6 拐头向下 |
| `RSI_GT_70` | RSI6 > 70（站上即卖，非仅上穿日） |
| `RSI_DEATH` | RSI6 下穿 RSI12 |

### 6.3 布林（N=20，k=2）

| id | 成立 |
|----|------|
| `BOLL_BREAK_MID` | 收盘上穿中轨 |
| `BOLL_BREAK_UP` | 收盘上穿上轨 |
| `PX_CROSS_BOLL_MID` | 收盘下穿中轨 |
| `PX_CROSS_BOLL_LOW` | 收盘下穿下轨 |

### 6.4 KDJ（N=9）

| id | 成立 |
|----|------|
| `KDJ_DEATH` | K 下穿 D |
| `KDJ_TOP_DIV` | 顶背离，指标用 K |
| `KDJ_TURN_DOWN` | K 拐头向下 |
| `KDJ_OVERBOUGHT` | K > 80（站上即卖） |
| `KDJ_BEAR_ALIGN` | `J < K < D`（持续即卖） |

### 6.5 MACD（12，26，9）

| id | 成立 |
|----|------|
| `MACD_DEATH` | DIF 下穿 DEA |
| `MACD_TOP_DIV` | 顶背离，指标用 DIF |
| `MACD_TURN_DOWN` | DIF 拐头向下 |
| `MACD_SHIFT_DOWN` | DIF 今天 &lt; 昨天（下降日都卖） |
| `MACD_TURN_AWAY` | HIST > 0 且 HIST 拐头向下 |
| `MACD_CROSS_ZERO` | DIF 下穿 0 |
| `MACD_LT_ZERO` | DIF &lt; 0（零轴下都卖） |

### 6.6 均线（固定周期）

不用请求里的短、长均线。

| id | 成立 |
|----|------|
| `PX_CROSS_MA` | 收盘下穿 SMA(20) |
| `MA_BEAR_ALIGN` | SMA5 &lt; 10 &lt; 20 &lt; 60（持续即卖，最早下标 59） |
| `MA5_CROSS_10/20/30/60` | SMA5 下穿对应均线 |
| `MA_BREAK_5/10/20/30` | 收盘下穿对应均线 |

### 6.7 K 线形态

前复权开收盘。缺开盘时用收盘代替（此时「收 &lt; 开」不成立）。

| id | 成立 |
|----|------|
| `BEAR_BAR` | 收 &lt; 开，且收 &lt; 前一根收 |
| `BEAR_DROP_N` | 收 &lt; 开，且 `C_i < C_{i−N}`（N = 5/10/13/15/20） |

```text
阴线下跌 N 日只比 C_i 与 C_{i−N}，中间收盘不参与
```

## 7. 同一天谁先买

只影响名额分配，不改变信号是否成立。分数取确认日（涨幅除外）。`NaN` 排在有分数之后。

| id | 方向 | 分数 |
|----|------|------|
| `CHANGE_DESC`（默认） | 大→小 | 今开 / 昨收 − 1（昨收 ≤ 0 → 0） |
| `CHANGE_ASC` | 小→大 | 同上 |
| `SIGNAL` / `COMPOSITE` / `ALLOC_UNIT` / `POSITION_DESC` | 大→小 | 金叉强度；成分排序用动量绝对值 |
| `MA` | 大→小 | 确认日 SMA(shortMa)，窗口未满 NaN |
| `AMOUNT_DESC` | 大→小 | `trans_amt_rmb` |
| `TURNOVER_DESC` | 大→小 | `turnover_ratio` |
| `FLOAT_CAP_ASC` | 小→大 | 流通 A 股 × 未复权收盘 |
| `TOTAL_CAP_ASC` / `DESC` | 小→大 / 大→小 | 总股本 × 未复权收盘 |
| `PB_ASC` / `PE_ASC` | — | 无源列，分数 NaN |

```text
momentumTopPct：排序后保留前比例（如 0.3 → 前 30%），至少 1 只
空或 ≥ 1 → 不截；合法范围夹到 5%～99%
```

## 8. 开盘能否成交

`limitRules` 默认 true。

| 检查 | 规则 |
|------|------|
| 停牌 | 含开始日、不含复牌日；无 K 线或开/收 ≤ 0 也不可交易 |
| 有公布价 | 未复权开盘 ≥ 涨停×(1−1e-4) 不能买；≤ 跌停×(1+1e-4) 不能卖 |
| 无公布价 | 前复权开盘 vs 前复权昨收×板幅，容差同上 |
| 板幅 | 只看 `st_hat` 戴帽区间 |

| 板块 | 前缀 | 板幅 |
|------|------|------|
| 主板 | `600/601/603/605`、`000/001/002/003` | 1996-12-16 起 10%；ST 且 ≥1998-04-22 为 5% |
| 创业板 | `300/301` | 至 2020-08-23：普通 10%/ST 5%；2020-08-24 起 20% |
| 科创板 | `688/689` | 2019-07-22 起 20% |
| 北交所 | `43/82/83/87/88/92` | 2021-11-15 起 30% |

`excludeSt = true`：买入日落在戴帽区间，或当前简称含 `ST`，则不买。不影响卖出。

```text
minFloatMktCapYi：确认日未复权收盘 × 流通 A 股（亿元）
无流通 A 股且打开下限 → 跳过
```

## 9. 组合回测结果

结果页十项绩效与曲线在回测完成后给出。`POST /run` 带全部成交；表格再按 `GET .../trades` 从进程内存分页。默认对照沪深300。`bt_job.result_json` 只留摘要；`barCount` = `candidateCount`。

### 9.1 净值

交易日 = 镜像日历 ∩ 对比指数交易日（不足 2 天则用指数日）。循环从第 2 个交易日起。指数无 K 线的日子不记净值点，但已发生成交仍保留。

```text
权益 = 现金 + Σ(股数 × 当日收盘)
峰值 = max(峰值, 当日权益)   // 从初始资金起
当日回撤 = 峰值 > 0 ? (峰值 − 当日权益) / 峰值 : 0
maxDrawdown = max(当日回撤)   // 正数；基准不参与
```

无 K 线的持仓按买入花费计价。期末快照用日历末日收盘；无 K 线则价格/市值 = 0。

### 9.2 收益与年化

```text
totalReturn = 最后权益 / 初始资金 − 1
年数 = max(1/252, 净值点数/252)
annualizedReturn = max(1e-12, 1 + totalReturn) ^ (1/年数) − 1
```

默认初始资金 1,000,000。无净值点时最后权益用剩余现金。

### 9.3 基准

默认 `000300`，加载**不复权**。

```text
benchmarkEquity = 初始资金 × (当日指数收盘 / 首根 >0 的收盘)
benchmarkReturn = 最后 benchmarkEquity / 初始资金 − 1
```

指数失败时用候选股等权曲线（代码加 `_EW`）代替。`buyHoldReturn` = `benchmarkReturn`。

### 9.4 Sharpe

年化无风险利率 2%，日利率 `0.02/252`。从初始资金到各净值点取 `r = 今/昨 − 1`，超额 `r − 0.02/252`（昨权益 ≤ 0 丢弃）。有效段 &lt; 2 → Sharpe = 0。

```text
均值 = Σ超额 / n
方差 = Σ超额² / n − 均值²     // 总体
sharpeRatio = 均值 / √方差 × √252
√方差 < 1e-12 → 0
```

### 9.5 换手

每日用收盘权益算权重（含现金，和为 1）；开跑前视为全现金。

```text
当日换手 = 0.5 × Σ|当日权重 − 上日权重|
turnover = 当日换手的平均     // 日均单边，不 ×252
```

权益 ≤ 0 的日子不计；无净值日 → 0。

### 9.6 成交、盈亏、胜率

| 字段 | 买入 | 卖出 |
|------|------|------|
| `price` | 开盘×(1+佣金+滑点) | 开盘×(1−佣金−滑点−印花税) |
| `shares` | 金额取整到 100 股；不够则按 1 股 | 全部 |
| `amount` | 股数×price，扣现金 | 股数×price，加现金 |
| `pnl` / `returnPct` | 0 | 卖出金额 − 买入花费；收益率 |
| `holdDays` | 0 | 卖出当天已加过的天数 |

```text
tradeCount = 完成的卖出笔数（清整仓算 1 笔）
winTrades = pnl > 0 的卖出笔数
winRate = tradeCount = 0 ? 0 : winTrades / tradeCount
```

`rejectedBuys` / `rejectedSells`：信号成立但开盘未成交。结果页盈亏比 = 盈利卖出平均 `returnPct` / 亏损卖出平均 `|returnPct|`（无亏损 → 0）。

### 9.7 结果页十项

| 页面 | 字段 |
|------|------|
| 持有期 | `holdingPeriodDays` |
| 策略累计收益 | `totalReturn` |
| 历史年化收益率 | `annualizedReturn` |
| 成功率 | `winRate` |
| 单次收益平均值 | `avgTradeReturn` |
| 盈亏比 | `payoffRatio` |
| 最大回撤 | `maxDrawdown`（正百分数） |
| 单次最大 / 最小收益 | `maxTradeReturn` / `minTradeReturn` |
| 交易次数 | `tradeCount` |

曲线：`(equity / initialCash − 1)` 与基准累计收益。`sharpeRatio`、`turnover`、`profitFactor`、拒单次数在接口摘要中，不在十格。
