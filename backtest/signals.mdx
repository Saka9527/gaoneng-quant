## 1. 信号日和成交日

组合回测（工作台 `POST /api/v1/portfolio/run`）的口径：

1. 指标全部在收盘价上计算。买入、卖出标记写在**确认日**那根 K 线的下标上。
2. 交易日 `T` 的开盘，读取的是**上一交易日**收盘已经写好的标记。
3. 成交价是 `T` 的开盘价，再扣费用。买入成交价 = 开盘 × (1 + 佣金 + 滑点)。卖出成交价 = 开盘 × (1 − 佣金 − 滑点 − 印花税)。默认佣金 `0.0003`，滑点 `0.0005`，印花税 `0.0005`。
4. 同一天先处理卖出，再处理买入。当天买进的仓位 `holdDays = 0`，当天不会被卖掉。
5. 停牌、缺 K 线、开盘价 ≤ 0 的日子不成交。`limitRules` 默认打开，涨跌停另见第 8 节。
6. `tPlusOne` 默认打开：买入日当天不能卖。下一交易日起可以卖。

`sellOnIndicator` 默认 `true`。设成 `false` 时卖出标记整段为 false，只按持股天数平仓。

未知的 `buySignal` 回落到 `SMA_GOLDEN`。未知的 `sellSignal` 回落到 `MA_DEATH`。

全市场接口 `POST /api/v1/universe/market-backtest` 只用金叉和死叉，并且在**确认日当天的收盘价**成交，不走 T+1、涨跌停、停牌、印花税和持股周期。见第 9 节。两条接口的收益不能直接对比。

## 2. 用哪一套价格

默认 `forwardAdjust = true`。开盘、收盘先乘前复权因子，再送进均线和指标。

面板里先按**库内最新** `cum_back` 做好前复权，任意回测结束日都能复用同一份面板。真正跑回测时再按结束日做点时前复权：每股乘一个系数 `不晚于结束日的 cum_back ÷ 最新 cum_back`。结束日不早于该股最新除权时系数为 1，直接复用面板对象。

等价写法：点时前复权价 = 未复权价 × (不晚于结束日的 `cum_back` ÷ 不晚于当日的 `cum_back`)。没有因子时乘数为 1。

因此：

- SMA、EMA、RSI、BOLL、KDJ、MACD、阴线、均线交叉，都在前复权开收盘上算。
- 涨跌停的**公布价**仍是未复权价。有公布价时，引擎用未复权开盘去比较。没有公布价时，用前复权昨收 × 板幅，开盘和昨收同一套复权，这条比较是自洽的。
- 成交额、换手直接用同花顺日行情的 `trans_amt_rmb`、`turnover_ratio`。流通市值是流通 A 股乘未复权收盘，总市值是总股本乘未复权收盘。股本来自 `corp_share_structure`。未复权开盘、收盘和这些原值先写入 DuckDB，预热时再装进内存。市盈率、市净率没有源列。

K 线序列按每只股票自己的交易日排列。停牌日没有这根 K 线，指标窗口会把停牌前后的交易日接在一起，中间不补空日。

窗口还没满的位置：指标写成 `NaN`，比较直接跳过；简单均线写成 `0`，金叉和死叉从下标 `longMa` 起读，此时短、长窗口都已满。

## 3. 共用判定

下面的「上一根」都是这只股票 K 线序列里的前一根，不是自然日的昨天。`NaN` 不参与比较。

| 名称 | 成立条件 | 最早可能的下标 |
|------|----------|----------------|
| 下穿 | 上一根 `A ≥ B`，这一根 `A < B` | 1，且两根都有效 |
| 上穿 | 上一根 `A ≤ B`，这一根 `A > B` | 1，且两根都有效 |
| 下穿水平 `L` | 上一根 `A ≥ L`，这一根 `A < L` | 1 |
| 高于水平 | 这一根 `A > L` | 该指标第一个有效值 |
| 低于水平 | 这一根 `A < L` | 同上 |
| 拐头向下 | 这一根 `<` 上一根，且上一根 `≥` 再上一根 | 2 |
| 下移 | 这一根 `<` 上一根 | 1 |
| 顶背离 | 回看 20 根（不含今天）：收盘 ≥ 这 20 根收盘的最大值，且指标 `<` 这 20 根指标的最大值 | 20 |

顶背离的价格最大值和指标最大值都只统计 `[i−20, i)`，不含当天。指标里出现 `NaN` 的那些根不进入指标最大值。20 根指标全是 `NaN` 时不触发。

## 4. 指标公式

周期是固定的，请求参数改不了。只有金叉、死叉、MA 顶背离和「成分按排序买入」的动量用请求里的 `shortMa`、`longMa`。默认短 20、长 60。`shortMa` 小于 2 或 `longMa` 不大于 `shortMa` 时，金叉和死叉整段不触发。

### 4.1 简单均线 SMA(N)

下标 `i`（从 0 计）在 `i ≥ N−1` 时：

```
SMA(N)_i = (C_i + C_{i-1} + … + C_{i-N+1}) / N
```

`C` 是前复权收盘。

### 4.2 指数均线 EMA(N)

先用前 `N` 根收盘的简单平均作为种子，放在下标 `N−1`。之后

```
k = 2 / (N + 1)
EMA_i = C_i × k + EMA_{i-1} × (1 − k)
```

对已经含有前导 `NaN` 的序列（MACD 的 DEA），先跳过开头的 `NaN`，再对后面的有限值做同样的 SMA 种子和 EMA。

### 4.3 RSI

用的是 Wilder 平滑，周期 `RSI_SHORT = 6`、`RSI_LONG = 12`。

记涨跌 `d_i = C_i − C_{i−1}`。上涨部分 `g_i = max(d_i, 0)`，下跌部分 `l_i = max(−d_i, 0)`。

第一个值在下标 `N`（不是 `N−1`）：用 `d_1 … d_N` 共 `N` 个涨跌的算术平均得到 `gain`、`loss`。之后

```
gain_i = (gain_{i-1} × (N − 1) + g_i) / N
loss_i = (loss_{i-1} × (N − 1) + l_i) / N
```

```
gain = loss = 0  →  50
loss = 0         →  100
否则             →  100 − 100 / (1 + gain / loss)
```

RSI6 从下标 6 起有效，RSI12 从下标 12 起有效。

### 4.4 布林带

`N = 20`，倍数 `k = 2`。中轨就是 SMA(20)。标准差是总体标准差（除以 `N`，不除以 `N−1`）：

```
方差 = Σ(C²) / N − 中轨²
上轨 = 中轨 + 2 × √方差
下轨 = 中轨 − 2 × √方差
```

从下标 19 起有效。方差算成负数时按 0。

### 4.5 KDJ

`N = 9`。RSV 用**收盘价**在最近 9 根里的最高和最低，不用 K 线最高价、最低价。

```
HH = max(C_{i-8} … C_i)
LL = min(C_{i-8} … C_i)
HH = LL 时 RSV = 50，否则 RSV = (C_i − LL) / (HH − LL) × 100
```

第一根有效 KDJ（下标 8）直接令 `K = D = RSV`，不用 50 做种子。之后

```
K_i = (RSV_i + 2 × K_{i-1}) / 3
D_i = (K_i + 2 × D_{i-1}) / 3
J_i = 3 × K_i − 2 × D_i
```

### 4.6 MACD

参数 12、26、9。

```
DIF = EMA(12) − EMA(26)
DEA = 对 DIF 做 EMA(9)（跳过 DIF 前面的 NaN）
HIST = DIF − DEA
```

柱状值是 `DIF − DEA`，不是 `2 × (DIF − DEA)`。DIF 从 EMA(26) 的第一根起有效，下标 25。DEA 还要再等 9 根有限的 DIF。

文案里的「MACD」在死叉、拐头、下移、下穿 0 轴、小于 0 这些规则里指的是 **DIF**。只有「拐头离开」用 HIST。

### 4.7 金叉强度

只在金叉当天有值，其它日子预计算强度保持 `1e-6`。

```
强度 = |SMA短 − SMA长| / SMA长
```

`SMA长 ≤ 0` 时强度保持 `1e-6`。`positionMode = INDICATOR` 时，当日买入预算按各候选的强度占强度合计的比例分配。

## 5. 买入规则

两条。标记写在确认日。引擎在下一交易日开盘才买，并且要求确认日的 K 线下标 `≥ longMa`（默认 60）。所以成分排序虽然从第 2 根就标成可买，默认参数下也要等到第 61 根（下标 60）之后才会进入候选。

再平衡只限制买入日，不限制卖出：

| `rebalance` | 哪些交易日可以买 |
|-------------|------------------|
| `DAILY`（默认） | 每个交易日 |
| `WEEKLY` | 周一；若上一交易日的星期几更大（跨周，例如周一休市后的周二），这一天也买 |
| `MONTHLY` | 与上一交易日不在同一个月 |

同一天还要过这些买入门槛，全部通过才下单：还没持有、因子成分包含这只股票（配了因子组合时看**上一交易日**的成分）、未因排除 ST 被去掉、流通市值不低于下限、开盘可以买、排序后仍在当日名额里、同行业未超上限、预算至少够 1 股。默认最多持有 10 只，每天最多新买 2 只，单票权重上限 10%，总仓位上限 100%。

### 5.1 `SMA_GOLDEN` 双均线金叉（默认）

确认日 `i`（`i ≥ longMa`）：

```
SMA(short)_{i-1} ≤ SMA(long)_{i-1}
且 SMA(short)_i > SMA(long)_i
```

默认即 SMA20 上穿 SMA60。相等后再严格上穿才算，贴着走不算。

### 5.2 `UNIVERSE_RANK` 成分股按排序买入

确认日下标 `≥ 1` 就标成可买，不看均线。谁先买由排序分决定。

动量回看长度 = `shortMa` 夹到 5～20，默认短均线 20，所以回看 20 根：

```
动量_i = C_i / C_{i−lookback} − 1
```

昨收或回看那根收盘 `≤ 0` 时动量为 0。强度是动量的绝对值，至少 `1e-6`。

这条规则几乎每天全池可买，预计算不建「当日买点代码」索引，引擎改为扫描整个股票池。

## 6. 卖出规则

38 条。只计算请求里选中的那一条。

卖出在确认日收盘成立后，下一交易日开盘卖出。和持股周期是**或**的关系：周期到了，或者指标到了，都会进入卖出列表。停牌、跌停、T+1 会把这一天的卖出拒掉，仓位留到之后的交易日再试。拒掉之后 `holdDays` 已经加过，下一天会再次因为周期到达而尝试卖出。

`holdDays` 计数：买入当天为 0；之后每个交易日循环一开始加 1；`holdDays ≥ holdingPeriodDays` 则当天开盘卖。默认 `holdingPeriodDays = 2`，即买入日之后的**第二个交易日**开盘卖出（指标若更早成立，会更早卖）。

| 买入日 | 下一交易日 | 再下一交易日 |
|--------|------------|--------------|
| 买入，`holdDays = 0`，当天不卖 | `holdDays = 1`，默认周期未到 | `holdDays = 2`，周期到达，开盘卖 |

### 6.1 跟短长均线走的三条

| id | 名称 | 计算 | 成立 |
|----|------|------|------|
| `MA_DEATH` | MA死叉日线（默认） | 周期用请求的短、长均线 | 下标 `i ≥ longMa`：上一根短 ≥ 长，这一根短 &lt; 长 |
| `MA_TOP_DIV` | MA顶背离日线 | **ta4j**：`SMA(shortMa)` 与最近 `shortMa+1` 根收盘的最高值 | 下标 `i ≥ shortMa+1`：当天收盘等于最近 `shortMa+1` 根收盘的最高值（含当天，并列也算），并且 SMA 今天 &lt; 昨天 |
| `HOLD_PERIOD` | 仅持股周期卖出 | 不计算指标 | 标记恒为 false，只等第 6 节的持股天数 |

`MA_TOP_DIV` 预计算走 ta4j。另一条「新高」写法把收盘和含当天在内的窗口最大值相比，这个比较恒成立，实际只剩「短均线今天 &lt; 昨天」。撮合读的是 ta4j 写好的数组。

ta4j 这条规则建 K 线时，最高价 = max(开盘, 收盘)，最低价 = min(开盘, 收盘)，成交量写 0。比较读的是收盘，高低价不影响结果。

## 7. 同一天多只股票谁先买

排序不改变买卖点是否成立，只决定名额不够时买哪几只。分数按**确认日**（上一交易日）取值，涨幅除外。`NaN` 排在有分数的后面。

| id | 方向 | 分数 |
|----|------|------|
| `CHANGE_DESC`（默认） | 大的在前 | 今日开盘 / 昨收 − 1。昨收 ≤ 0 时为 0 |
| `CHANGE_ASC` | 小的在前 | 同上 |
| `SIGNAL` | 大的在前 | 第 4.7 节的金叉强度；成分排序用动量绝对值 |
| `COMPOSITE` | 大的在前 | 与 `SIGNAL` 相同 |
| `ALLOC_UNIT` | 大的在前 | 与 `SIGNAL` 相同 |
| `POSITION_DESC` | 大的在前 | 与 `SIGNAL` 相同 |
| `MA` | 大的在前 | 确认日的 SMA(shortMa)，窗口未满为 NaN |
| `AMOUNT_DESC` | 大的在前 | 同花顺 `trans_amt_rmb`，确认日原值 |
| `TURNOVER_DESC` | 大的在前 | 同花顺 `turnover_ratio`，确认日原值 |
| `FLOAT_CAP_ASC` | 小的在前 | 不晚于确认日的流通 A 股 × 未复权收盘 |
| `TOTAL_CAP_ASC` | 小的在前 | 不晚于确认日的总股本 × 未复权收盘 |
| `TOTAL_CAP_DESC` | 大的在前 | 同上 |
| `PB_ASC` / `PE_ASC` | — | 本地没有市净率、市盈率列，分数为 NaN |

`momentumTopPct` 在排序之后截断。例如 `0.3` 保留分数排在前面的 30%，至少留 1 只。空或 ≥ 1 表示不截。合法范围夹到 5%～99%。

## 8. 买卖点成立之后，开盘还要能成交

`limitRules` 默认 true。

1. 停牌区间内不成交。停牌含开始日，不含复牌日。当天没有 K 线，或开盘、收盘 ≤ 0，也视为不能交易。
2. 有当日公布涨跌停价时：用**未复权开盘**去比。未复权开盘 ≥ 涨停价 × (1 − 0.0001) 不能买；未复权开盘 ≤ 跌停价 × (1 + 0.0001) 不能卖。公布价本身也是未复权价。没有未复权开盘时才退回序列里的开盘。
3. 没有公布价时，用前复权昨收和板幅。前复权开盘触及涨停一侧不能买，触及跌停一侧不能卖，容差同样是 `1e-4`。认不出的代码，或规则还没生效的日期，不拦截。

板幅只看戴帽区间 `st_hat`，不用当前简称。

| 板块 | 代码前缀 | 板幅 |
|------|----------|------|
| 主板 | `600/601/603/605`、`000/001/002/003` | 1996-12-16 起 10%；落在 ST 区间且日期 ≥ 1998-04-22 时为 5% |
| 创业板 | `300/301` | 2009-10-30 起至 2020-08-23：普通 10%，ST 区间 5%；2020-08-24 起 20% |
| 科创板 | `688/689` | 2019-07-22 起 20% |
| 北交所 | `43/82/83/87/88/92` | 2021-11-15 起 30% |

`excludeSt` 默认 false，ST 可以买。设成 true 时，买入日若落在戴帽区间，或者当前简称（`security.sec_short_name_cn`）包含 `ST`（不区分大小写），这只股票不买。简称这条把该股整段回测都标成 ST。简称里已经去掉 ST、但历史上有戴帽区间的日子，仍由区间挡住。排除 ST 不改变卖出。

流通市值下限 `minFloatMktCapYi`：用确认日未复权收盘 × 截至确认日的流通 A 股，换成亿元。没有流通 A 股的股票在打开这个下限时会被跳过。

## 9. 全市场双均线扫描

全市场扫描和组合回测的金叉、死叉定义相同。成交不同：

- 金叉当天、空仓时，用**当天收盘**买入，满仓。
- 死叉当天、持仓时，用**当天收盘**卖出。
- 费用只加佣金和滑点，买卖都扣。没有印花税、T+1、涨跌停、停牌、持股周期、仓位上限。
- 初始资金按 1 计。K 线短于 `longMa + 1`，或价格无效，记失败，不进平均和中位数。

跑完后的汇总：

| 字段 | 算法 |
|------|------|
| `totalReturn` | 单只期末权益 − 1。期末若仍持仓，用最后一根收盘计价，不再扣费 |
| `avgReturn` | 成功股票收益的算术平均 |
| `medianReturn` | 成功股票收益从小到大排序后，取下标 `个数 / 2`（偶数个时取靠后的那个中位） |
| `top` / `bottom` | 按收益从高到低，各最多 10 只 |
| `trades` | 买入和卖出各算 1 次 |
| `computeMs` | 只含这次向量计算，不含装行情 |

这一条接口没有年化、最大回撤、Sharpe、换手、胜率。

## 10. 组合回测结果

工作台结果页的十项绩效和收益曲线在组合回测跑完后给出。最大回撤库存是正数，页面也按正的百分数显示。`POST /api/v1/portfolio/run` 的 `trades` 带全部成交。结果页表格仍按 `GET /api/v1/portfolio/jobs/{jobId}/trades` 从本进程内存分页取。收益曲线默认对照沪深300。

写入 `bt_job.result_json` 的是同一套绩效的摘要。曲线和成交在库里是空数组。`barCount` 写的是股票数 `candidateCount`，不是 K 线根数。

### 10.1 净值怎么记

交易日取镜像交易日历和对比指数交易日的交集。交集不足 2 天时，直接用指数自己的交易日。循环从第二个交易日开始，第一个交易日没有净值点，也没有成交。

某一天指数上没有这根 K 线时，这一天不记净值。当天的买卖如果已经发生，仍然留在成交里。`tradingDays` 等于净值点的个数，等于 `equityCurve` 的长度。

每个净值点在当天买卖做完之后，用收盘价计价：

```
权益 = 现金 + Σ(股数 × 当日收盘)
```

现金是扣过买入、加上卖出之后的余额。收盘和开盘都是前复权价（默认）。当天这只股票没有 K 线时，这只持仓按买入花费的金额计价，不沿用最近收盘。

峰值从初始资金起算。每个净值点：

```
峰值 = max(峰值, 当日权益)
当日回撤 = 峰值 > 0 时 (峰值 − 当日权益) / 峰值，否则 0
```

`maxDrawdown` 是这些当日回撤里的最大值，用正数表示。基准涨跌不参与回撤。

期末持仓快照用日历最后一天的收盘。那天没有 K 线则价格写 0，市值也是 0。`holdDays` 是持仓计数器在最后一个交易日加完之后的值。

### 10.2 策略收益和年化

```
totalReturn = 最后一笔权益 / 初始资金 − 1
```

净值一个点都没有时，最后一笔权益用剩余现金，此时通常还没有任何仓位。

```
年数 = max(1 / 252, 净值点数 / 252)
annualizedReturn = max(1e-12, 1 + totalReturn) ^ (1 / 年数) − 1
```

一年按 252 个净值点。净值点多于或等于 1 时，年数就是 `净值点数 / 252`，指数部分等于 `252 / 净值点数`。只有 1 个点时，会把这一天的收益按 252 次方年化。`1 + totalReturn` 小于 `1e-12` 时，按 `1e-12` 再做幂，避免收益为 −100% 时出现无效数。

默认初始资金 1,000,000。

### 10.3 基准收益

对比指数默认 `000300`，加载时**不复权**。

```
benchmarkEquity = 初始资金 × (当日指数收盘 / 基准第一根大于 0 的收盘)
benchmarkReturn = 最后一笔 benchmarkEquity / 初始资金 − 1
```

分母是加载到的指数序列里第一根大于 0 的收盘，一般是区间第一天，而净值从第二天才开始记。所以曲线上的第一个基准点通常已经相对起点走了一天，第一个点的 `benchmarkEquity` 往往不是初始资金。

指数加载失败时，用候选股收盘合成一条等权曲线代替，代码名加后缀 `_EW`：每只股票以这批里最长那条 K 线的第一天收盘为 1，当天值是 `收盘 / 该股基期收盘` 的平均数；当天一只都对不上时记 1。开盘写成和收盘相同。之后仍用上面的公式算 `benchmarkReturn`。

`result_json.buyHoldReturn` 写的就是这个 `benchmarkReturn`。

### 10.4 Sharpe

年化无风险利率 2%，日利率 `0.02 / 252`。`result_json.riskFreeRate` 写的就是这个 2%。

从初始资金走到每一个净值点，逐段算超额收益 `r − 0.02/252`，其中 `r = 今权益 / 昨权益 − 1`。昨权益 ≤ 0 的段丢掉。有效段少于 2 时，Sharpe 为 0。

```
均值 = Σ(r − 0.02/252) / n
方差 = Σ(r − 0.02/252)² / n − 均值²
标准差 = √方差
sharpeRatio = 均值 / 标准差 × √252
```

方差除以 `n`，是总体标准差。标准差小于 `1e-12` 时，Sharpe 为 0。

### 10.5 换手

每个净值日用收盘权益算权重，现金也占一份，各项相加为 1。开跑前视为全部现金。

```
当日换手 = 0.5 × Σ|当日权重 − 上日权重|
turnover = 这些当日换手的平均
```

权益 ≤ 0 的日子不计入。没有净值日时换手为 0。这个数是日均单边换手，没有再乘 252。

### 10.6 成交、盈亏、胜率

一笔成交的字段：

| 字段 | 买入 | 卖出 |
|------|------|------|
| `price` | 开盘 × (1 + 佣金 + 滑点) | 开盘 × (1 − 佣金 − 滑点 − 印花税) |
| `shares` | 按金额取整到 100 股；不够 100 股时退回按 1 股取整 | 全部卖出 |
| `amount` | 股数 × price，从现金扣除 | 股数 × price，加回现金 |
| `pnl` | 0 | 卖出金额 − 买入时花费的金额 |
| `returnPct` | 0 | 卖出金额 / 买入花费 − 1。买入花费为 0 时为 0 |
| `holdDays` | 0 | 卖出当天、计数器已经加过之后的天数 |

`tradeCount` 是完成的卖出笔数，一笔卖出清掉一只股票的整仓，算一笔完整交易。买入单不计入。`winTrades` 是 `pnl > 0` 的卖出笔数，持平不算赢。

`rejectedBuys`、`rejectedSells` 是信号已经成立、但开盘没成交的次数。卖出侧包含 T+1 当天、停牌、跌停、当天没有 K 线。买入侧包含停牌、涨停、当天没有 K 线。被拒的卖出当天已经把 `holdDays` 加过，仓位还在，下一天会再试。

结果页的成功率是：

```
tradeCount = 0 时，winRate = 0
否则 winRate = winTrades / tradeCount
```

分母是完成的卖出笔数。`profitFactor` 仍是卖出盈利金额合计 / 亏损金额绝对值，写在任务摘要里，结果页不展示。结果页的盈亏比是另一套：盈利卖出的平均 `returnPct` / 亏损卖出平均 `returnPct` 的绝对值；没有亏损卖出时记 0。单次收益平均、最大、最小都只看卖出的 `returnPct`。买入单不参与。

### 10.7 工作台结果页

十个格子从左到右。涨为红、跌为绿。最大回撤、盈亏比、持有期、交易次数用中性颜色。最大回撤按库存的正数显示成百分数。

| 页面 | 字段 | 来源 |
|------|------|------|
| 持有期 | `holdingPeriodDays` | 配置里的持股天数，显示成「2天」 |
| 策略累计收益 | `totalReturn` | 第 10.2 节 |
| 历史年化收益率 | `annualizedReturn` | 第 10.2 节 |
| 成功率 | `winRate` | 第 10.6 节 |
| 单次收益平均值 | `avgTradeReturn` | 卖出 `returnPct` 的平均 |
| 盈亏比 | `payoffRatio` | 盈利卖出平均收益率 / 亏损卖出平均收益率的绝对值，保留 2 位 |
| 最大回撤 | `maxDrawdown` | 第 10.1 节，显示正的百分数 |
| 单次最大收益 | `maxTradeReturn` | 卖出 `returnPct` 的最大 |
| 单次收益最小值 | `minTradeReturn` | 卖出 `returnPct` 的最小 |
| 交易次数 | `tradeCount` | 第 10.6 节，显示成「N次」 |

收益曲线画两条累计收益率：`(equity / initialCash - 1)` 和 `(benchmarkEquity / initialCash - 1)`。图例是「回测累计收益」和基准名称加「收益」。基准缺省或代码为 `000300` 时名称是沪深300。纵轴单位是百分数，不画回撤线。

`sharpeRatio`、`turnover`、`profitFactor`、`rejectedBuys`、`rejectedSells` 仍在接口和任务摘要里，不在这十个格子上。`computeMs` 只含撮合，`loadMs` 含装行情和辅助数据。

## 11. 选股因子

因子不是买卖点。配了 `factorCombo` 时，因子服务按区间给出每日成分；组合引擎只在**上一交易日**成分里的股票上检查买入标记。卖出不看成分。

本地预热算出来的行情因子如下。涨跌幅按百分数。分位取当日有限值里从低到高排序后的 80%～100%，下标从 `floor(n × 80 / 100)` 到 `ceil(n × 100 / 100)`。

| id | 入选 |
|----|------|
| `calc_px_up` | 涨跌幅 > 0 |
| `calc_px_up5` | 涨跌幅 ≥ 5 |
| `calc_px_dn5` | 涨跌幅 ≤ −5 |
| `calc_lim_up` | 收盘 ≥ 涨停价 × 0.999，且两个价格都 > 0 |
| `calc_lim_down` | 收盘 ≤ 跌停价 × 1.001，且两个价格都 > 0 |
| `calc_amt_p80` | 成交额处于当日最高的约 20% |
| `calc_turn_p80` | 换手率处于当日最高的约 20% |
| `calc_vol_p80` | 成交量处于当日最高的约 20% |
| `calc_st` / `calc_suspend` | 按戴帽、停牌区间把区间内每个交易日涂进成分，两端都含当天 |

词典里其它因子来自 `gn_factor_signal`，筛选比较的是信号行上的涨跌幅、成交额、换手、市值、市盈率、量比，运算符为命中、大于、小于、区间、分位。那些数值不是本服务算出来的指标。
