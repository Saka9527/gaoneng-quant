本库有两类表：服务自己的业务表，以及从同花顺精简过来的行情镜像。回测热路径读的是本地 DuckDB，见 [本地行情文件 data/market.duckdb](/data/duckdb)。同花顺源库字段见 [同花顺库表结构：lm_ths_db](/data/ths/index)。

- Host: `rm-uf68ip7k7isrv895h7o.mysql.rds.aliyuncs.com:6306`
- 库名: `gngltdb`
- 账号: `gngltdb_rw`（密码用环境变量 `APP_DB_PASSWORD`）
- 业务表在部署时建好，启动不再建表

## 业务表

| 表 | 谁写 | 说明 |
|----|------|------|
| [`bt_job`](/data/gngltdb/bt_job) | 组合回测 | 任务状态、请求 JSON、结果摘要。成交只在进程内存 |
| [`bt_portfolio_strategy`](/data/gngltdb/bt_portfolio_strategy) | 工作台保存策略 | 交易配置，以及最近一次收益曲线和期末持仓 |
| [`gn_factor`](/data/gngltdb/gn_factor) | 产品种子 / 板块刷新 | 工作台选股因子 |
| [`gn_factor_signal`](/data/gngltdb/gn_factor_signal) | 因子信号、板块刷新 | 页面预览用最新一个信号日；选股服务的三年成分在本机快照里 |
| [`gn_factor_combo`](/data/gngltdb/gn_factor_combo) | 保存动态组合 | 用户因子组合 JSON |
| `gn_user` / `gn_user_browse` / `gn_user_follow` | 产品种子 | 演示用户、最近浏览、关注 |
| `gn_strategy` / `gn_strategy_nav` / `gn_strategy_position` / `gn_strategy_rebalance` | 策略榜单种子 | 展示用净值、持仓和调仓。当前工作台不读 |

## 行情镜像（精简列，近三年全 A）

这些表是同花顺源表的子集，列名和源库不完全相同。同步脚本见 [行情镜像（THS → gngltdb）](/data/mirror)。

| 镜像表 | 同花顺源表 | DuckDB 表 |
|--------|------------|-----------|
| [`ls_sec_basic_info`](/data/gngltdb/ls_sec_basic_info) | `ls_sec_basic_info` | `security` |
| [`ls_stock_daily_quotation`](/data/gngltdb/ls_stock_daily_quotation) | `ls_stock_daily_quotation` | `bars` |
| [`ls_index_daily_quotation`](/data/gngltdb/ls_index_daily_quotation) | `ls_index_daily_quotation`（只同步主要对比指数） | `index_bars` |
| [`stock_adjust_factor_table`](/data/gngltdb/stock_adjust_factor_table) | `stock_adjust_factor_table` | `adjust` |
| [`bt_limit_price`](/data/gngltdb/bt_limit_price) | `shsz_stock_up_and_dl_price` | `limit_price` |
| [`bt_st_hat`](/data/gngltdb/bt_st_hat) | `risk_warning_situation` | `st_hat` |
| [`bt_suspend`](/data/gngltdb/bt_suspend) | `suspen_prompt_info` | `suspend` |
| [`bt_float_share`](/data/gngltdb/bt_float_share) | `ls_stock_free_float_share` | `float_share` |
| [`bt_trade_calendar`](/data/gngltdb/bt_trade_calendar) | `exchange_opening_calendar`（上交所开市日） | `calendar` |

总市值、市盈率、市净率、上市日期没有镜像列。买入排序里这三项没有本地分数；新股前几个交易日不设涨跌停的窗口也没有上市日期可用。
