- 说明: 用户保存的组合策略。工作台保存时写入配置并立刻回测。每个交易日 17:00 行情同步进内存后重跑，更新最近一次收益和持仓。失败不覆盖上一份成功结果
- DDL: `schema-gngltdb.sql`
- 引擎: InnoDB

| 字段 | 类型 | 说明 |
|------|------|------|
| `strategy_id` | varchar(64) PK | 组合策略 ID |
| `user_id` | varchar(64) | `X-User-Id` |
| `name` | varchar(128) | 策略名称 |
| `config_json` | mediumtext | `PortfolioTradeConfig` JSON |
| `created_at` | bigint | 创建时间 epoch ms |
| `updated_at` | datetime(3) | 自动更新 |
| `last_run_at` | bigint | 最近一次回测完成时间 |
| `last_status` | varchar(16) | `SUCCESS` / `FAILED` |
| `last_error` | varchar(2000) | 失败原因 |
| `as_of_date` | date | 回测截止日 |
| `total_return` / `annualized_return` / `max_drawdown` / `sharpe_ratio` | double | 列表用的收益摘要 |
| `holding_count` | int | 期末持仓只数 |
| `result_json` | longtext | 净值曲线和期末持仓。不含逐笔成交 |

索引：`idx_bt_ps_user (user_id, created_at)`。
