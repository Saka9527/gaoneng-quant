- 说明: 工作台选股因子。左侧分组读这张表
- DDL: `schema-product.sql`
- 引擎: InnoDB

| 字段 | 类型 | 说明 |
|------|------|------|
| `factor_id` | varchar(64) PK | 因子 ID |
| `name` | varchar(128) | 名称 |
| `description` | varchar(1024) | 说明 |
| `select_logic` | varchar(1024) | 选股逻辑文案 |
| `category_l1` | varchar(32) | 推荐 / 独家 / 板块 |
| `category_l2` | varchar(64) | 二级分类 |
| `status` | varchar(16) | `ONLINE` / `OFFLINE`，默认 ONLINE |
| `source_type` | varchar(32) | `MANUAL` / `THS_SECTOR` / `THS_FLOW` / `THS_HOTMONEY` / `PROPRIETARY` |
| `source_ref` | varchar(128) | 外部引用键 |
| `signal_count` | int | 信号个数 |
| `day_change_pct` | decimal(12,4) | 当日涨跌幅 |
| `ret_1w` … `ret_ytd` | decimal(12,4) | 1 周、1 月、3 月、6 月、1 年、今年以来收益 |
| `hot_rank` | int | 近 5 日涨幅热门排序，越小越热 |
| `updated_at` | datetime(3) | 自动更新 |

索引：`idx_gn_factor_cat (category_l1, category_l2)`，`idx_gn_factor_hot (hot_rank)`。
