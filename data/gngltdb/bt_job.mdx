- 说明: 回测任务与结果
- 引擎: InnoDB

## 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `job_id` | varchar(64) PK | 任务 ID，如 `bt_xxxx` |
| `status` | varchar(16) | PENDING / RUNNING / SUCCESS / FAILED |
| `client_request_id` | varchar(128) | 客户端透传 |
| `user_id` | varchar(64) | 发起用户，来自请求头 `X-User-Id`。启动时若缺列会补上 |
| `dataset_id` | varchar(128) | 组合任务里是股票池或因子组合标识，不再登记单票数据集 |
| `strategy` | varchar(32) | 买入信号代码，如 `SMA_GOLDEN`、`UNIVERSE_RANK` |
| `request_json` | mediumtext | 完整请求 |
| `result_json` | longtext | 成功时的摘要 JSON。字段见 [查询组合回测任务](/api-reference/portfolio-backtest/job)。曲线和成交是空数组 |
| `error_message` | varchar(2000) | 失败原因 |
| `created_at` | bigint | epoch ms |
| `finished_at` | bigint | epoch ms |
| `updated_at` | datetime(3) | 自动更新 |
