---
title: "ls_index_daily_quotation`（gngltdb 镜像）"
description: "主键 (index_code, td_date)。索引 idx_td_date (td_date)。"
---

- 说明: 对比指数日 K。源库约 6112 万行、约 17 GB，镜像只同步 `000300`、`000001`、`399001`、`399006`、`000905`、`000016`
- 源表: [ls_index_daily_quotation](/data/ths/ls_index_daily_quotation)
- 迁入 DuckDB: `index_bars`。`latest_index`→`close_index`，`vol`→`volume`

| 字段 | 类型 | 说明 |
|------|------|------|
| `index_code` | varchar(16) | 与 `td_date` 组成主键 |
| `td_date` | date | 交易日 |
| `open_index` / `high_index` / `low_index` / `latest_index` | decimal(20,6) | 开高低收 |
| `vol` | decimal(24,4) | 成交量 |
| `sec_id` | varchar(64) | 指数证券 ID |
| `index_short_name` | varchar(128) | 简称 |
| `exchg_code` | varchar(32) | 交易所。DuckDB 不保留此列 |
| `isvalid` | tinyint | 默认 1 |
