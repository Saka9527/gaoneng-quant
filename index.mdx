## 系统里有什么

| 部分 | 职责 |
| --- | --- |
| `java-quant-backtest` :8080 | 产品页、组合回测、任务摘要 |
| `factor-service` :8081 | 按区间返回每日选股成分 |
| `data/market.duckdb` | 回测实际读取的日 K、复权、涨跌停、停牌、ST |
| `gngltdb` | 可写业务表，以及同花顺行情的精简镜像 |
| `lm_ths_db` | 同花顺源库。`quant.ths.mode=ths` 时直接读 |

本服务负责行情读取、回测计算、结果摘要和产品壳。交易、账户和完整终端 UI 在桌面客户端。
