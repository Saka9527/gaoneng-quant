一条因子要能被别人独立复现。定义时至少写清下面这些项。

| 项 | 要回答的问题 | 例子 |
| --- | --- | --- |
| 名称 | 叫什么 | 上升通道 |
| 类别 | 属于哪类特征 | 价格动量 |
| 逻辑 | 为什么可能有效 | 趋势向上且回撤浅的股票更可能延续 |
| 输入数据 | 用哪些字段，什么复权口径 | 前复权开高低收 |
| 频率 | 多久算一次 | 日频，收盘后 |
| 窗口 | 最少需要多少根历史 | 25 根 |
| 输出 | 布尔还是数值，数值方向 | 布尔，为真表示入选 |
| 无效值 | 窗口不够、停牌、缺数据怎么处理 | 记为假 |
| 适用范围 | 用在哪些股票上 | 全 A，剔除上市不足 25 日 |

## 编写步骤

<Steps>
  <Step title="写公式">先用通达信或伪代码写出原文，再逐个中间量写清口径。</Step>
  <Step title="定边界">明确每个中间量从第几根开始有效，无效时输出什么。</Step>
  <Step title="交叉验证">
用独立实现做参照，例如通达信、同花顺里的原公式，或另写一份脚本，逐日比对输出。

| 要点 | 做法 |
| --- | --- |
| 样本 | 覆盖不同板块、不同市值的股票，区间不少于一年 |
| 边界日 | 上市初期窗口不足、停牌前后、除权除息日 |
| 判定 | 布尔信号逐日一致；数值允许小于 1e-6 的浮点误差 |
| 差异 | 先查复权口径和 `EMA` 种子取法，再查数据缺失 |
  </Step>
  <Step title="留档">按上面的定义表写成一页算法说明，附原文公式和参数。参数或口径改动时记录版本、日期和原因，便于回看历史结果。</Step>
</Steps>

<Tip>
共用中间量的因子要一起维护。比如牛线定义变了，上升通道、回踩辅助线和辅助金叉都要同步。
</Tip>
