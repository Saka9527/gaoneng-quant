下面这些能力在因子研究类产品里常见。**当前代码没有实现**，文档里不提供参数或接口。

| 能力 | 现状 |
| --- | --- |
| 页面内因子表达式 | 没有。公式写死在 `FormulaSignals` |
| 自定义算子、自定义基础因子类 | 没有 |
| 离群值处理、标准化、行业中性 | 没有 |
| IC、IR、分层收益检验页 | 没有。收益验证走组合回测 |
| 分析师一致预期、舆情因子 | 没有对应数据源 |
| 分钟或 tick 因子 | 回测频率是日线 |

已经能扩展的部分：

- 新增一条布尔选股公式：实现 `calc_*`，写入成分，并在 [因子列表](/factor/catalog) 补一页。
- 新增一条买卖点：在 `TradeSignalCatalog.builtins()` 注册，编号大写，同步 [指标与买卖点](/backtest/signals)。
- 板块因子：行业成分已接 `stk_corp_ic`。概念成分要等 ID 对齐后再做同样的刷新。

P0 是策略净值、持仓、调仓的真实日批，以及按真实用户编号保存关注。
