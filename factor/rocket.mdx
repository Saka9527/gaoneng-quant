当天收盘标记。原文：

```
买线:=EMA(C,2);
卖线:=EMA(SLOPE(C,30)*5+C,20);
火箭信号区域:买线>卖线;
```

`C` 是前复权收盘。这里的 `EMA` 按通达信递推，第一根有效值就作为种子。

```
EMA_t = (2 * X_t + (N - 1) * EMA_{t-1}) / (N + 1)
```

`SLOPE(C,30)` 是最近 30 根收盘对时间的最小二乘斜率。时间序号取 `0 … 29`，序号平移不改变斜率。分母是常数 `30 * Σk² − (Σk)²`，`k` 从 0 到 29。斜率从下标 29 起有效。卖线的输入在斜率无效时也无效，EMA 从第一根有效输入重新起算。
