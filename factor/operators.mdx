## 通达信写法

| 写法 | 含义 |
| --- | --- |
| `OPEN` `HIGH` `LOW` `CLOSE` | 开高低收，技术指标默认用前复权价 |
| `C` | `CLOSE` 的简写 |
| `REF(X, n)` | 向前第 n 根 K 线的值 |
| `MA(X, n)` | n 日简单平均 |
| `EMA(X, n)` | 指数平均：`(2 * X + (n - 1) * 上一根) / (n + 1)` |
| `SLOPE(X, n)` | 最近 n 根对时间的最小二乘斜率 |
| `COST(n)` | 筹码分布中累计比例达到 n% 的价格 |
| `AND` | 条件都成立才为真 |

`EMA` 的种子有两种常见取法：第一根有效值，或前 n 根的简单平均。两种取法在前几十根会有差异，复现外部公式时要先确认原文用的是哪一种。

## 比较算子

下面的「上一根」是这只股票 K 线序列里的前一根，不是自然日的昨天。

| 名称 | 成立条件 |
| --- | --- |
| 下穿 | 上一根 A ≥ B，这一根 A &lt; B |
| 上穿 | 上一根 A ≤ B，这一根 A &gt; B |
| 区域 | 这一根 A &gt; B，不看上一根 |
| 拐头向下 | 这一根小于上一根，且上一根大于等于再上一根 |
| 顶背离 | 回看 20 根（不含今天）：收盘不低于这 20 根收盘的最大值，且指标低于这 20 根指标的最大值 |

<Note>
「金叉区域」和「金叉」含义不同。区域是每一天都可能为真的位置关系，金叉只在交叉当天为真。
</Note>
