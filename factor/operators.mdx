选股公式和买卖点是两套规则。公式决定「这天这只股票在不在池子里」。买卖点决定「昨收确认后，次日开盘买不买、卖不卖」。

## 选股公式里出现的写法

| 写法 | 含义 |
| --- | --- |
| `OPEN` `HIGH` `LOW` `CLOSE` | 前复权开高低收 |
| `REF(X, n)` | 向前第 n 根 K 线的值 |
| `MA(X, n)` | n 日简单平均 |
| `EMA(X, n)` | 指数平均。种子是前 n 根的简单平均 |
| `AND` | 条件都成立才为真 |

牛线在上升通道、回踩辅助线、辅助金叉里相同：滞后 0 到 18 的权重是 20 到 2，滞后 19 不参与，滞后 20 的权重是 1，分母 210。生命线是牛线的 5 日均线。

系统没有可配置的算子库，也没有在页面里写表达式再编译的入口。改公式时同步 [六条公式](/factor/formulas) 对应的文档页。

## 买卖点里的比较

下面的「上一根」是这只股票 K 线序列里的前一根，不是自然日的昨天。

| 名称 | 成立条件 |
| --- | --- |
| 下穿 | 上一根 A ≥ B，这一根 A &lt; B |
| 上穿 | 上一根 A ≤ B，这一根 A &gt; B |
| 拐头向下 | 这一根小于上一根，且上一根大于等于再上一根 |
| 顶背离 | 回看 20 根（不含今天）：收盘不低于这 20 根收盘的最大值，且指标低于这 20 根指标的最大值 |

完整公式、38 条卖出和成交口径见 [指标与买卖点](/backtest/signals)。

</Note>
