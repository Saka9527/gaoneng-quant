产品库就是可写库里的字典，不是单独的因子仓库服务。

| 表 | 谁写入 | 谁读取 |
| --- | --- | --- |
| `gn_factor` | 产品种子、板块刷新 | 工作台左侧列表、详情头图字段 |
| `gn_factor_signal` | 因子信号、板块刷新 | 页面预览用的最新一个信号日 |
| `gn_factor_combo` | 用户保存动态组合 | 回测请求里的因子组合 |

成分服务启动时把三年快照装进 `membership.bin`。2026-10-14 的启动日志是 276 个因子、9,267,897 行、79,777 个因子日，覆盖 2023-09-12 至 2026-10-12。`quant.membership.rebuild-on-startup` 为 false。不要为了对文档去调重建：重建会用 `gn_factor_signal` 覆盖这份三年快照。

表结构见 [gn_factor](/data/gngltdb/gn_factor)、[gn_factor_signal](/data/gngltdb/gn_factor_signal)、[gn_factor_combo](/data/gngltdb/gn_factor_combo)。

行业成分路径是 `stk_corp_ic` → `gn_factor` / `gn_factor_signal`，启动刷新或 `refresh-sectors`。概念指数成分 ID 还没对齐，暂不刷新。
