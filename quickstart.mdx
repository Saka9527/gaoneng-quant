## 启动

在 `java-quant-backtest` 目录：

```bash
mvn -q spring-boot:run
```

| 入口 | URL |
| --- | --- |
| 服务 | http://127.0.0.1:8080 |
| 产品 UI | http://127.0.0.1:8080/product/ |
| Swagger | http://127.0.0.1:8080/swagger-ui.html |
| OpenAPI | http://127.0.0.1:8080/v3/api-docs |

选股成分是另一个进程，端口 `8081`，见 [每日成分](/api-reference/constituents/constituents)。
