## 三、缺失功能（交互/产品规则未完全对齐）

1. **盘中 5 分钟自动刷新**（日涨幅/今日龙头/部分信号）— 前端未做定时器，后端无实时源。  
2. **收益红涨绿跌** — 前端已做；策略卡片「创建后收益曲线每日收盘更新」— 需批处理。  
3. **关注上限文案** — API 已返回「最多关注50/30…」「最多开启5个推送…」；需客户端统一 Toast。  
4. **下架隐藏不删关注** — 查询已过滤 `OFFLINE`；恢复 ONLINE 后应再出现（已满足查询侧）。  
5. **浮层推送排队（同时仅 1 个）** — 未实现 WebSocket/SSE 实时浮层。  
6. **信号表排序/行业漏斗/分页/部分勾选加自选** — UI 简化版，未全量。  
7. **策略详情左侧列表与 C 端权限「量化版 3.0」** — 无权限中间件。  
8. **母站顶栏（自选/个股/沪深…）与底部指数条** — 本服务只做量化子站壳。  
9. **PRD 截图内大量「点击图片查看电子表格」字段表** — 已按可见 UI + 正文规则实现；若字段表与现实现有细差，需产品确认导出原表再对齐。

## 四、建议优先级

1. **P0** 策略净值/持仓/调仓真实日批（否则榜单不可信）  
2. **P0** 统一登录 + 关注数据按真实 userId  
3. **P1** 板块成分等权收益 + 沪深300 基准接 THS  
4. **P1** 可接 THS 的因子（龙虎/大宗/高管/资金流）换成真实 SQL  
5. **P2** 寻龙诀/热点掘金/竞价类专有数据接入  
6. **P2** 实时刷新、推送浮层、视频上传、因子后台 CRUD
