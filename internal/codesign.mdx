## 二、缺失数据

| 数据 | 原型用途 | 现状 |
|------|----------|------|
| 策略风格标签 | 短线、优选、激进、资金门槛「5万以上」 | 只有卖出时点 `sell_type` |
| 上架时间 / 试运行时间 | 详情头 | 无字段 |
| 真实策略净值、持仓、调仓 | 曲线、持股、调仓记录 | `gn_strategy_*` 多为种子演示，不是日批回测 |
| 近一年独立绩效 | 切换「近一年」后的年化/胜率 | 曲线可前端截取；胜率、盈亏比、年化仍是全区间种子值 |
| 调仓轨迹 | 买卖点画在曲线上 | 用已有调仓日期打点，不是逐笔轨迹坐标 |
| 行业/概念/地域板块成分与收益 | 选股范围 | 行业已从 `stk_corp_ic` 写入信号；概念 ID 未对齐；无地域 |
| 核心股池成分 | 8 类股池 | 无对应结果表 |
| 基本面 / 特色指标 / 消息面条件值 | 定制筛选 | 日 K 与少量辅助表，无财务截面、无消息事件流 |
| 策略容量、订阅人数、权限「量化版」 | 运营配置 | 无 |
| 视频文件 | 视频讲解 | 仅 URL，无上传存储 |
| 统一账号 | 登录、收藏上限 | 演示头 `X-User-Id` |

## 三、功能对照（2026-10-12 第二轮）

| 原型功能 | 状态 |
|----------|------|
| 定制向导：选股范围 / 核心股池 / 技术面 / 保存 | 已做。因子来自 `gn_factor`，保存走 `POST /portfolio/strategies`。地域、周期、基本面无数据，页面标明未接入 |
| 调仓轨迹 + 时间筛选 | 已做。曲线上按调仓日打买卖点，记录可按日期筛选 |
| 策略广场、查看回测 | 已做入口。广场复用榜单数据；「查看回测」进入个人回测记录（任务未按策略 ID 归档） |
| 我的策略：收藏 / 定制 / 调仓消息 | 已做 |
| 收藏超限提示 | 接口报错时榜单会 Toast |
| 后台风格、置顶、容量、权限、订阅上限 | 未做持久化，后台文案已说明 |
| 母站行情终端 | 不做 |

## 四、建议顺序

1. 策略净值 / 持仓 / 调仓改为真实日批，否则榜单对齐原型也不可对外当实盘业绩。  
2. 补风格标签、上架时间等展示字段。  
3. 概念与地域选股范围。  
4. 定制向导已接到现有因子组合与策略保存接口；基本面、地域、8 类股池仍等数据，不另写一套引擎。
