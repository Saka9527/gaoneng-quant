## 买入排序 `buyPriority`（14）

日循环只读准备好的分数。成交额、换手用同花顺日行情原值。流通市值、总市值用股本表股数乘未复权收盘。市盈率、市净率没有源列，分数为空。

| id | 名称 | 分数从哪来 |
|----|------|------------|
| `SIGNAL` | 指标信号强度 | 预计算强度 |
| `COMPOSITE` | 综合 | 预计算强度 |
| `MA` | MA | 开跑前写成一列 |
| `ALLOC_UNIT` | 配置单位大小 | 预计算强度 |
| `POSITION_DESC` | 每笔仓位从大到小 | 预计算强度 |
| `TOTAL_CAP_ASC` | 总市值由小到大 | 总股本 × 未复权收盘 |
| `TOTAL_CAP_DESC` | 总市值由大到小 | 总股本 × 未复权收盘 |
| `AMOUNT_DESC` | 成交额由大到小 | 日行情 `trans_amt_rmb` |
| `TURNOVER_DESC` | 换手率由大到小 | 日行情 `turnover_ratio` |
| `PB_ASC` | 市净率由小到大 | 无本地列 |
| `PE_ASC` | 市盈率由小到大 | 无本地列 |
| `FLOAT_CAP_ASC` | 流通市值由小到大 | 流通 A 股 × 未复权收盘 |
| `CHANGE_DESC` | 涨幅由大到小 | 开盘 / 前收 |
| `CHANGE_ASC` | 涨幅由小到大 | 开盘 / 前收 |

`AMOUNT_DESC`、`TURNOVER_DESC`、`FLOAT_CAP_ASC`、`TOTAL_CAP_ASC`、`TOTAL_CAP_DESC` 会读未复权行情。流通市值下限同样用流通 A 股和未复权收盘。

## 卖出信号 `sellSignal`（38）

只计算选中的那一条。`sellOnIndicator` 为 false 时不计算卖出标记，只按持股周期平仓。

公式、周期、信号日和成交日见 [指标、买卖点与回测结果](/backtest/signals)。指标类 35 条在收盘价上一次写成 `boolean[]`。`MA_DEATH` 用请求里的短、长均线做一次滚动计算。`MA_TOP_DIV` 仍走 ta4j。`HOLD_PERIOD` 不预计算，信号恒为 false。

## 涨跌停与 ST

`limitRules` 默认 true。停牌日不能成交。有当日公布价时，开盘达到或超过涨停不能买，开盘达到或低于跌停不能卖。

没有公布价时按板块生效日和该股 `st_hat` 区间取板幅：主板 1996-12-16 起 10%，主板 ST 区间自 1998-04-22 起 5%；创业板 2009-10-30 至 2020-08-24 前 10%（ST 区间 5%），2020-08-24 起 20%（含 ST）；科创板 2019-07-22 起 20%（含 ST）；北交所 2021-11-15 起 30%（含 ST）。规则生效前或认不出的代码不拦截。当前简称里的 ST 不拿来回填历史板幅。

`excludeSt` 默认 false。勾上之后，戴帽区间或当前简称含 ST 的股票不再买入。
